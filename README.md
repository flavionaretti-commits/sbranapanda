# SBRANAPANDA – PWA

Versione PWA del progetto Scratch **Sbranapanda**, ideato e programmato originariamente da Flavio Naretti.

## Pubblicazione su GitHub Pages

Repository consigliata: `sbranapanda`

Caricare nella radice del repository:
- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `service-worker.js`
- cartella `assets`
- cartella `icons`

Poi attivare GitHub Pages da **Settings → Pages → Deploy from a branch → main / root**.

URL previsto:
`https://flavionaretti-commits.github.io/sbranapanda/`

## Categorie

Le categorie e le selezioni vengono memorizzate sul singolo dispositivo tramite `localStorage`.
Il tasto **Ripristina predefinite** ricrea la configurazione iniziale del progetto Scratch.

## Nota sulla voce

La pronuncia usa la sintesi vocale disponibile nel browser/dispositivo. Se non è presente una voce italiana, il gioco continua normalmente mostrando il testo della categoria estratta.
